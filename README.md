# LabGuard

LabGuard is a Windows lab device management system. The current implementation is through v0.6 individual software management; v0.7 bulk deployment is planned but not implemented.

For a fresh coding-agent handoff, start with [Development State](docs/LabGuard_Development_State.md), then [Architecture](docs/LabGuard_Architecture.md). See [LAN deployment](docs/LabGuard_LAN_Deployment.md) for setup and project READMEs under `labguard-server`, `labguard-client`, and `labguard-dashboard` for their commands.
